# Checklist de geração

- [ ] Arquivo completo e nome preservado.
- [ ] Interface `Props` exportada e estende `CodayComponentProps`.
- [ ] Componente funcional é export default.
- [ ] `componentDefinition` usa ID estável e semver.
- [ ] Cada prop configurável possui controle.
- [ ] Defaults têm o tipo correto e são JSON.
- [ ] Categories, order, responsive e bindable foram escolhidos conscientemente.
- [ ] Condições são declarativas.
- [ ] Slots e arrays preservam IDs e keys estáveis.
- [ ] Assets possuem alt text.
- [ ] Eventos carregam somente payload JSON.
- [ ] Hooks possuem dependências e cleanup corretos.
- [ ] Motion respeita reduced motion.
- [ ] Render é compatível com SSR.
- [ ] Imports pertencem à allowlist.
- [ ] Sizing declara width/height.
- [ ] Nenhuma API interna do editor é acessada.
