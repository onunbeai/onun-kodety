# Prompt cookbook

## Componente novo

“Crie `PricingCard.tsx` para Coday, com Props explícitas, `defineComponent`, sizing e controles Content/Layout/Style. Title e price devem aceitar CMS. Entregue o arquivo completo.”

## Componente responsivo

“Adicione responsividade a layout, gap e typography. O componente deve receber valores resolvidos e não consultar media queries para essas props.”

## CMS em collection

“Permita conectar title a string/text e image somente a image do item corrente. Preserve fallback estático e não acesse o WordPress diretamente.”

## Slots

“Crie header Slot, content Slot e actions Slots com máximo três itens. Use ReactNode somente no tipo runtime; persista referências de slot.”

## Correção

“Analise os diagnósticos fornecidos, preserve nomes e comportamento, corrija somente o contrato inválido e devolva o arquivo completo mais uma lista curta de correções.”

## Migration

“Crie migration determinística de 1.1.0 para 2.0.0 que renomeie `gap` para `layoutGap`, preserve props desconhecidas e não acesse APIs externas.”
