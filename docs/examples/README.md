# Exemplos

- `basic-card`: controles primitivos, imagem, spacing e layout responsivo.
- `responsive-hero`: layout e tipografia com overrides.
- `image-gallery`: Array/Object, assets e reorder.
- `nested-slots`: Slot/Slots e identidade de camadas.
- `cms-list`: lista e campos conectáveis ao CMS.
- `animated-component`: efeito com cleanup e `prefers-reduced-motion`.

Todos usam a mesma API pública e passam pelo mesmo compiler/runtime do produto.
