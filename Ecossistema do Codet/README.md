# Ecossistema do Codet

Este diretório reúne produtos que compartilham a linguagem visual e os padrões de qualidade do Code, mas são distribuídos como plugins independentes.

## Produtos

- [`kodety-rocket/`](./kodety-rocket/) — motor gratuito de performance para WordPress, instalável e funcional sem o plugin principal.

Cada produto mantém slug, namespace, opções, assets, cache, permissões e ciclo de atualização próprios. Estar neste diretório representa pertencimento ao ecossistema, não dependência de runtime.
