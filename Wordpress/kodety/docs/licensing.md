# Open source capabilities

Onun Kodety is distributed under GPL-3.0-only. Installed features do not require a serial key, subscription, trial, account, license server, activation token or periodic check. CMS collections and items have no commercial limits.

WordPress capabilities, REST nonces, login, project permissions and third-party provider credentials remain required for the operations they protect. Optional extensions still need to be installed and enabled.

`Kodety_License` and the historical `pro` capability discriminator are internal compatibility interfaces for existing projects and extensions. They do not represent a paid plan. There are no activation REST routes or license admin screens.
