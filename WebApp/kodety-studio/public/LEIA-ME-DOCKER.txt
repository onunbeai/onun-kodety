ONUN KODETY — EASYPANEL / DOCKER

1. Envie o arquivo kodety-studio-docker.zip em Source > Upload.
2. Em Build, selecione Dockerfile.
3. Se o painel pedir o caminho, use ./Dockerfile.
4. Não informe Build Command, Install Command ou Start Command.
5. Configure a porta HTTP do serviço como 80.
6. Vincule o domínio e ative HTTPS antes de abrir o Studio.

O container usa um servidor Node.js pequeno para servir o build pronto e manter
a ponte pública do MCP. npm, PHP e MySQL não são executados no servidor. O
WordPress e o Builder continuam rodando localmente no navegador.

Para usar o MCP de um cliente externo, mantenha o projeto aberto no Studio. O
relay apenas encaminha a chamada; a credencial e as permissões são verificadas
pelo plugin dentro do WordPress local.
