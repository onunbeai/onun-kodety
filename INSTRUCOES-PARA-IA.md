# Onun Kodety

Este repositório contém o editor visual HTML e a integração WordPress do Onun Kodety.

- Edite os fontes; os diretórios `dist/` e `Wordpress/kodety/assets/` são gerados.
- Preserve rotas, formatos de projeto, nomes internos `kodety` e `coday` necessários para compatibilidade.
- O produto não deve exigir serial, plano pago ou os serviços privados do Kodety.
- Preserve autenticação WordPress, nonces, permissões e proteção de arquivos.
- Use credenciais locais ou variáveis de ambiente para integrações; nunca grave segredos.
- Rode as verificações relevantes e informe limitações de teste.
- A publicação do repositório pertence à organização Onun no GitHub. O identificador exato da organização e o remoto devem ser confirmados no momento da publicação. Nunca envie para o antigo repositório pessoal.

Veja `README.md`, `CONTRIBUTING.md` e `docs/open-source-preparation.md`.
